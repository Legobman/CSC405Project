# CSC405Project
My project for CSC 405

Project title: CSC05Project

Dataset source (URL): https://www.kaggle.com/datasets/harshadapatil31/student-performance-and-study-habits-dataset?resource=download

Project objective: To answer the question of if we predict the change when comparing a student’s previous grade to their final exam score based on the number of hours that they slept and studied.

Instructions for running the code:
- Get the project
- clone
    ```
    git clone https://github.com/Legobman/CSC405Project.git
    ```
- OR download zip.
- Open the project in Jupyter Notebook or VS Code.
- Build and run the main class.
